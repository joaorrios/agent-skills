# Intent Ledger Pass

Check the approach against the ledger of user decisions you receive with these instructions. The ledger is evidence of what the user decided; the approach must answer to it.

Resolve each reference entry against its named source first. Then report every entry as one of:

- **honored** — the approach carries it out; cite where.
- **handed off** — another change, issue, or doc explicitly takes it; name and cite that owner.
- **out of scope** — it bears on a later stage, not on the approach; name the stage and say why.
- **missing** — the approach is silent on it.
- **contradicted** — the approach does otherwise; cite both. An open question the approach settles without the user is contradicted.
- **unresolved** — a reference whose source you cannot reach, or an ambiguous entry whose readings lead to different outcomes for this approach.

Missing, contradicted, and unresolved entries are substantive findings. Remain read-only.

Return the ledger as a list, one line per entry with its status and evidence, findings first.
