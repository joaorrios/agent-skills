# Initiatives

- One objective can carry several initiatives, each with a goal, a done
  criterion, and the "Now" tasks that serve it. A single-track project
  has one initiative named after the objective.
- Opening, pausing, dropping, or closing one is the user's call.
- Paused: no new tasks; current tasks keep their follow-ups. Tell its
  live workers, and resume only when the user reactivates it.
- Closing or dropping one first settles each of its "Now" tasks: done,
  dropped, or moved to another initiative.
- A **done** task (as SKILL.md defines it under Delegate), a dropped
  task, and a closed or dropped initiative leave the state for
  `archive.md`, newest first, as one line each: date, task or
  initiative, name, its initiative, outcome or reason, commit or
  reference. Never delete a line there.
